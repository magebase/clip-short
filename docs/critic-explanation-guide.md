# How to explain each suggested edit

Every action shown to an editor must contain:

1. **Current state:** what is wrong in the current render.
2. **Evidence:** exact timestamp(s), visible object/face/diagram region, and measurement where available.
3. **Expected state:** what the viewer should see or understand instead.
4. **Action:** the typed renderer operation and parameter values.
5. **Expected quality effect:** composition, readability, narrative clarity, visual relevance, pacing, or audio.
6. **Risk/trade-off:** what could get worse (context, face size, source-art integrity, campaign duration, etc.).
7. **Observed outcome:** actual before/after measurements and Muse's post-render review.
8. **Decision source:** Muse suggestion, human selection, verified outcome, or ranker order.

Do not expose private chain-of-thought. Give concise evidence-grounded reasons. Never claim a numerical confidence is a calibrated probability unless calibration has been measured. Never claim an action improved campaign performance before actual campaign data is available.
