# clip-short v2.3 — Evidence, Format Direction, and Approval Contract

## 1. Required per-clip evidence

- `output_sha256`
- technical: `ffprobe`, `decode_test`, `black_freeze_scan`, `audio_loudness`, `av_sync`
- speaker switching: per-beat `active_speaker_id`, `visible_speaker_id`, `speaker_match_confidence`, `shot_type`, `face_bbox_norm`
- diagram treatment: per-beat `diagram_roi`, `semantic_state`, `roi_only_change`, `readable_labels`, `evidence_frame_sha256`
- illustrated narration: per-beat `expected_objects`, `observed_objects`, `semantic_relevance`, `object_bbox_norm`, `object_prominence`, `evidence_frame_sha256`
- reviewer: `provider`, `method`, `model`, `reviewer_id`, `reviewer_version`, `reviewed_output_sha256`, `timestamps`, `evidence_frame_hashes`
- thumbnail: `headline_count`, `headline_bbox_norm`, `focal_bbox_norm`, `face_eye_overlap`, `mobile_ocr_pass`, `semantic_match`, `crop_completeness`, `thumbnail_sha256`
- `hud_persistence`
- caption: `transcript_provenance`, `timing_alignment`, `review_status`, `ass_sha256`
- campaign: `campaign_id`, `min_seconds`, `max_seconds`, `policy_source`, `rule_id`, `checked_at`, `rule_excerpt`, `config_hash`
- `human_approval`

## 2. Batch rules

- Per-clip provenance only; no ambiguous batch-level scalar.
- `PASS_STATUS_UNSUBSTANTIATED` and `BATCH_PASS_UNSUBSTANTIATED` are critical.
- `not_checked` is not a pass.
- Empty review findings without inspected-frame provenance are not a pass.

## 3. Format direction

- Podcast: minimal HUD, speaker-first camera, restrained phrase captions.
- Technical: diagram ROI, complete labels, semantic callouts, honest treatment label.
- Illustrated narration: object prominence, preserve art style, minimal HUD/captions.

## 4. Approval

`READY_FOR_APPROVAL` is not publication. `APPROVED` requires human identity, timestamp, and output hash.
