# clip-short v2.2 — Evidence-Backed Visual Quality Contract

## Purpose

v2.1 proved the pipeline can measure change. v2.2 proves the change is relevant, the objects are present, and every PASS is supported by per-clip evidence.

## 1. Diagram / supporting ROI

- Change is measured on the supporting-visual ROI, not the whole frame.
- Speaker, captions, and HUD are masked or excluded.
- Evidence records `roi`, `masked_rois`, and `change_basis`.
- A crop with no semantic change is not progressive explanation.
- If the source has no demonstration, use `STATIC_DIAGRAM_WITH_CALLOUTS`.

## 2. Expected / observed objects

Every expected object has a status:

| Status | Meaning |
| :--- | :--- |
| `verified` | Registered detector found it above threshold |
| `not_detected` | Detector ran and found insufficient evidence |
| `not_checked` | No detector registered; fail closed |

`object_checks: []` never proves the scene is correct.

## 3. Independent reviewer identity

Reports record `reviewer_id`, `reviewer_version`, and `independent: true`. An empty findings list without identity is not evidence.

## 4. Thumbnail composition audit

- Exactly one declared text layer.
- Detected face rectangle and headline collision check.
- Text-block evidence; no subtitle fragments or HUD duplicate.
- Mobile readability at 180px width.

## 5. Per-clip provenance

Each clip stores its own git SHA, renderer version, campaign config hash, and source media hash. Batch-level-only provenance is invalid.

## 6. Batch validator

`python3 scripts/validate_clip_short_report.py batch_report.json`

Returns `REVIEW_REQUIRED` and `UNSUPPORTED_PASS` when a PASS lacks required evidence.

## 7. Format-aware art direction

Podcasts, diagrams, illustrations, screen recordings, slides, gaming, and performance each have explicit visual rules. See `subskills/art-direction.md`.

## 8. Non-goals

- No fabricated B-roll.
- No automated publishing or bounty claims.
- No claim of semantic verification without a detector or vision model.
