# clip-short v2.1 — Quality and Correctness Contract

## Purpose

v2.0 proved the router can distinguish source formats. v2.1 proves the rendered
edit actually implements the selected treatment and that the report is backed by
evidence from the exported MP4.

## Four independent gate statuses

| Status | Meaning |
| :--- | :--- |
| `TECHNICAL_PASS` | Container, codecs, resolution, loudness, true peak, black/freeze checks pass. |
| `EDITORIAL_PASS` | Treatment conformance, semantic frame utility, face/object visibility, and thumbnail checks pass. |
| `CAMPAIGN_PASS` | Campaign duration, rights, disclosures, account, hashtags, and content rules pass. |
| `READY_FOR_APPROVAL` | All three gates pass; human approval still required before publishing. |

One score never overrides a critical failure in another gate. The legacy
`QAStatus.PASS` is retained for compatibility and maps to
`READY_FOR_APPROVAL` only when all gates pass.

## Treatment conformance

Every plan must produce a `TreatmentSpec` before rendering:

- `PROGRESSIVE_DIAGRAM_ZOOM`: at least two semantic beats; the supporting visual
  must change between beats; the harness/model region must remain readable.
- `DYNAMIC_SPEAKER_SWITCHING`: a relevant face is visible in every beat unless
  the beat is explicitly marked as intentional B-roll; mic-only shots fail.
- `SCENE_BY_SCENE`: scene changes must align with narrative beats; low-information
  shots fail the frame-utility floor.

After rendering, `evaluate_conformance(spec, sampled_frames)` compares the actual
frames. Identical supporting visuals across diagram beats fail with
`TREATMENT_NOT_IMPLEMENTED`.

## Independent vision review

`HeuristicVisionReviewer` is deterministic and separate from the planner. It
emits structured findings with timestamps, severity, issue, and suggestion, and
returns `RENDER_REVISION` when a major/critical finding exists. A vision-model
adapter may replace it, but the planner must never approve its own render.

## Semantic visual QA

- Per-frame utility combines luminance variance and edge density.
- Empty or near-empty frames fail the utility floor.
- Beat-to-beat change is measured on downscaled grayscale frames.
- Object presence checks that require a vision model are recorded as
  `unverified_objects`, never silently passed.

## Thumbnail QA

- Exactly one primary headline.
- No subtitle fragments, transcript text, or duplicate HUD headline.
- Headline must not overlap the detected face/eye region.
- Readability is tested after downscaling to mobile display size.

## Campaign policy evidence

Every report records `campaign_id`, `min_seconds`, `max_seconds`, and the policy
source. A non-default duration ceiling requires an explicit campaign file and a
rationale; it is never an unnoticed exception.

## Reproducibility manifest

Every batch report records:

- git commit SHA
- skill version
- renderer version
- classifier / layout version
- campaign configuration hash
- source media hash
- sampled-frame evidence hashes

## Non-goals for v2.1

- Full multi-candidate retrieval and ranking.
- Automated publishing or bounty claims.
- Model-generated B-roll that is not present in the source.
- Training on raw view counts.
